تسيير غيابات التلاميذ — حزمة البناء

محتويات المشروع:
- www/index.html: واجهة التطبيق الحالية وسجل الغيابات الشهري.
- server/server.js: السيرفر المحلي وواجهات تسجيل الدخول والتخزين.
- desktop/: قالب تطبيق Windows Electron، يُجهّز تلقائيًا عند بناء EXE.
- tools/prepare-android.js: تجهيز Node.js المدمج داخل APK.
- .github/workflows/build.yml: بناء APK وEXE من GitHub Actions.

طريقة البناء دون تثبيت أدوات على الحاسوب:
1) ارفع جميع محتويات هذا المجلد إلى مستودع GitHub جديد.
2) افتح تبويب Actions.
3) اختر Build Ghiyabat APK and EXE ثم Run workflow.
4) عند نجاح البناء، نزّل APK وEXE من Artifacts أو من صفحة Releases.

أول تشغيل:
- أنشئ حساب المسؤول مرة واحدة باسم مستخدم من 3 أحرف وكلمة مرور من 8 أحرف على الأقل.
- الأجهزة الفرعية يجب أن تتصل بعنوان IP المحلي للجهاز المضيف؛ هذه الحزمة الأولى ما زالت تحتاج اختبارًا فعليًا على الأجهزة قبل اعتماد المزامنة نهائيًا.

ملاحظات مهمة:
- ملفات البناء مُعدة، لكن لم يُشغّل GitHub Actions بعد؛ لا يمكن اعتبار APK/EXE مبنيين أو مختبرين قبل نجاح Workflow.
- ملف الواجهة يستخدم مكتبة XLSX من CDN عند الحاجة للاستيراد/التصدير، لذلك هذه الوظيفة تحتاج إنترنت ما لم تُضمّن المكتبة محليًا.
- قواعد التنبيه الموجودة حاليًا في الواجهة محسوبة بالساعات. قاعدة الأيام المتتالية (مع احتساب الجمعة والسبت ضمن التسلسل) لم تُستبدل بعد، حتى لا نغيّر منطقًا قبل تثبيت متطلبات عتبات الإشعارات.

تحديثات (أكتوبر 2026):
- عند إنشاء قسم يُملأ جدول استعمال الزمن تلقائيًا: الأحد/الإثنين/الأربعاء/الخميس من 1 إلى 8، الثلاثاء من 1 إلى 4، السبت فارغ (والحد الأقصى 8 ساعات يوميًا)، ويمكن التعديل.
- الولاية والبلدية قائمتان منسدلتان (58 ولاية و1541 بلدية، مضمّنة دون إنترنت).
- زر «تحميل نموذج Excel فارغ» في تبويب الأقسام والتلاميذ، ثم الاستيراد (يحدّث التلميذ إن تكرر الرقم المدرسي).
- الإشعارات حسب أيام الغياب المتتالية غير المبرر: إشعار أول 3، ثاني 7، مضمون 15، فصل 30 (قابلة للتعديل في الإعدادات).
- تبويب «التبريرات»: شهادة طبية بفترة (لا تصل إشعارات) وحضور الولي (يصفّر العدّاد).
- الفصل (بقرار المجلس التأديبي أو بعد 30 يومًا): يُحذف من قائمة القسم ويبقى في قاعدة البيانات، مع «إعادة إدماج».
- الإرسال عبر واتساب/SMS يبقى يدويًا (يفتح الرسالة جاهزة).
- مكان الميلاد: اختيار ولاية ثم بلدية من قائمتين.
- الطباعة: تُفتح معاينة داخل التطبيق فيها زر «طباعة» وزر «إغلاق» (وتعمل مع زر الرجوع وEsc). على أندرويد زر «مشاركة / حفظ للطباعة» يصدّر ملفًا يُفتح بالمتصفح ويُطبع أو يُحفظ PDF.
- واتساب/SMS: يُفتحان خارج التطبيق (على ويندوز يفتح واتساب في المتصفح الافتراضي).
- الأساتذة: الاسم + المادة (قائمة مواد الثانوي مع إمكانية إضافة مادة) + الأقسام التي يدرّسها.
- استعمال الزمن: اختيار مادة كل ساعة، فيُعرف أستاذ كل حصة تلقائيًا.
- غياب الأستاذ (ندوة، يوم دراسي، مرض، ظروف عائلية، بدون مبرر) أو منصب شاغر: تُحسب حصص مادته ضائعة تلقائيًا في كل أقسامه خلال الفترة، ولو عوّضه أستاذ مادة أخرى.
- تقديم حصة: لا تُحسب الحصة الأصلية ضائعة.
- التقارير: الحصص الضائعة حسب القسم والمادة، وحسب المادة، وحسب الأستاذ (أيام الغياب والتوزيع على الأقسام والأسباب) مع تصدير Excel.

تحديثات (أكتوبر 2026 — نسخة المشرف التربوي):
- التطبيق خاص بالمشرف التربوي. حساب المسؤول (admin) يُنشأ أول تشغيل ويبقى تسجيل الدخول كما هو.
- المسؤول وحده يضيف المشرفين ويعدّلهم ويحذفهم من تبويب «المشرفون» (يظهر للمسؤول فقط): يكتب الاسم واللقب بالفرنسية وتاريخ الميلاد.
- اسم المستخدم = الحرف الأول من اللقب + نقطة + الاسم، وكلمة المرور = اسم المستخدم + سنة الميلاد. أمثلة: لقب aissa اسم allel مولود 1987 → a.allel / a.allel1987 ؛ لقب boumaza اسم mounir مولود 1987 → b.mounir / b.mounir1987.
- تعديل المشرف أو حذفه يُنهي جلساته الحالية فورًا.
- الإمضاء في التقارير والكشف الشهري والإشعارات المطبوعة اختياري من الإعدادات: بدون إمضاء / الناظر / المدير / المستشار التربوي (واسم صاحب الإمضاء).
- حُذفت حقول المشرف العام والمشرف الرئيسي ومشرف التربية من الإعدادات والمطبوعات.
- زر «اتصل بنا» في شريط التبويبات وفي شاشة الدخول: نافذة فيها البريد والهاتف وواتساب وفيسبوك وإنستغرام، مع زر نسخ لكل وسيلة.
- تعديل الحساب وتغيير كلمة المرور من الإعدادات (حسابي) لكل مشرف؛ يلزم إدخال كلمة المرور الحالية. إذا غيّرها المشرف لم تعد تظهر عند admin، وتعديل admin للمشرف يعيدها إلى الصيغة الافتراضية.
